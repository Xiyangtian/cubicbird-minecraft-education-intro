# 我的世界教育版 · 体验课（课程资源页）

方块鸟 Cubicbird 的 **《我的世界教育版》体验课**资源页 —— 4 节课，学生在这里下载当节课的世界、复制改造程序。

👉 **打开网页就是给学生用的页面**：`index.html`

---

## 这是什么

一节直播课里，学生要在两个时间点回到这个页面：

```
① 上课开始 → 下载今天这节课的世界 → 进游戏做任务
② 做完任务（或老师说到时间了）→ 回页面复制改造程序 → 回游戏改造
```

页面就是为这两件事存在的：**老师不用在直播里口播一串网址**。

## 仓库里有什么

| 文件 / 目录 | 说明 |
|---|---|
| `index.html` | 页面本体（自包含：HTML + CSS + 一点 JS，没有构建步骤） |
| `config.js` | ⭐ **配置文件** —— 改这里控制"上到第几节"、老师区开关、课程名 |
| `worlds/lesson1~4.mcworld` | 四节课的世界（学生下载的正式版） |
| `worlds/lesson1~4-debug.mcworld` | 调试版（带跳关按钮、命令可见）—— 只在老师区出现 |

## 四节课

| 节 | 名称 | 学到 | 成果 | 世界大小 |
|---|---|---|---|---|
| 1 | 让机器人铺路 | 顺序执行（走 / 砸 / 转 / 放） | 一条路 | 300 KB |
| 2 | 造一座桥 | 填充与替换 | 一座桥 | 304 KB |
| 3 | 盖一座塔 | 循环与嵌套 | 一座塔 | 301 KB |
| 4 | 搭自己的房子 | 综合运用（+ 一点点命名数据） | 一座房子 | 253 KB |

## 老师：上课前改一行

打开 `config.js`：

```js
window.课程配置 = {
  进度: 1,          // ⭐ 上到第几节了：1~4。后面的课会自动变灰、按钮点不动
  显示老师区: false, // 老师自己看的时候改成 true
  课程名: "我的世界教育版 · 体验课",
  机构名: "方块鸟 Cubicbird",
  版本: "v1 · 2026-10-06",
};
```

| `进度` | 页面上看到 |
|---|---|
| `0` | 四节全锁着（还没开课） |
| `1` | 只有第 1 节能点，第 2~4 节灰掉 |
| `3` | 第 1~3 节能点，第 4 节锁着 |
| `4` | 四节全开 |

**上过的课一直可以点**（学生补下载、补课用）。改完**刷新页面**就生效。

## 学生：一节课的三个动作

**① 下载世界**
点卡片上的「⬇ 下载世界」→ 打开 **Minecraft Education** → 在「开始游戏」这一页点最下面的 **「导入」** → 选刚下载的那个文件。

**② 进游戏做任务**
跟着老师一关一关做。（进去先**等 3 秒**，世界正在平整场地。）

**③ 做完任务回页面拿改造程序**
点「复制程序链接」→ 回到游戏按 **`C`** 打开 Code Builder：

1. 如果里面已经开着别的程序：先点右上角的 **🏠 房子按钮**回到首页
2. 点 **「导入」** → 选 **「导入网址…」**
3. **粘贴**刚才复制的链接 → 点 **「继续！」**
4. 回游戏，在聊天栏敲这节课的指令（`铺路` / `搭桥` / `建塔` / `建房`）

## 要改内容的话

| 想改什么 | 改哪里 |
|---|---|
| 哪几节开放、课程名、机构名、版本 | `config.js` |
| 每节课的文案 / 成就清单 / "可以改什么" | `index.html` 里那个 `课程数据` 数组 |
| 配色 | `index.html` 最上面 `:root` 里那 8 个色值（方块鸟配色） |
| 加一节课 | `课程数据` 里加一项（同时要加 `worlds/lessonN.mcworld`） |

### ⚠️ 世界改版之后

`worlds/` 里的是**拷贝**。如果世界重新生成过，必须**重新拷一份到这里**，否则学生下到的是旧版。
