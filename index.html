怎么用（三步）

  1. 先下载世界：点卡片上的「⬇ 下载世界」。下好之后打开 Minecraft Education， 在「开始游戏」这一页点最下面的 「导入」，选你刚下载的那个文件。
  2. 进游戏做任务：你会站在自己的场地里，跟着老师一关一关做。
  3. 做完任务回这个网页：点「复制程序链接」，然后回到游戏里按 C 打开 Code Builder：
    ① 如果里面已经开着别的程序，先点右上角的 🏠 房子按钮回到首页
    ② 点 「导入」 → 选 「导入网址…」 → 粘贴 → 点 「继续！」

常见问题

世界下载了，怎么导进游戏？

打开 Minecraft Education → 在「开始游戏」这一页点最下面那个「导入」 → 选你刚下载的那个 .mcworld 文件。（文件一般在浏览器的「下载」文件夹里。）

按 C 打不开 Code Builder？

要先进到世界里（在主菜单按是没用的）。还打不开就举手找老师 —— 有时是第一次打开需要多等一会儿。

「复制程序链接」点了没反应？

手动选中下面那行灰色网址，按 Ctrl+C（Mac 是 ⌘C）复制，一样能用。

按 C 打开后，找不到「导入」按钮？

说明里面已经开着一个程序了 —— 那些按钮只在首页才有。点右上角的 🏠 房子按钮回到首页， 就能看到 「导入」了。

程序导进去了，机器人不动？

三个地方挨个看一眼：① 你是不是站在绿方块（施工位）上；② 聊天栏里敲的指令名对不对 （铺路 / 搭桥 / 建塔 / 建房）；③ 程序里有没有先「给机器人方块」。

后面几节课为什么点不动？

还没上到那一节 —— 上完老师会把它打开。上过的课一直可以点，想重新下载世界随时都行。

    上课注记

    • 进世界后等 3 秒再动 —— 世界正在平整场地，这时候跑会掉下去。
    • 学生说「机器人不动」，先看聊天栏有没有报错，再看是不是没站在绿方块上。
    • 第 3 节建塔：提醒学生①那条填充的模式要选「空心」，选错会变成实心大方块。
    • 第 4 节建房：最上面那三块「把 宽 设为 …」是设置，别删；删了就重新导入程序。
    • 改造区/工地上的向导 NPC 有「重置」和「回到工地」按钮，学生改坏了点一下就能重来。
    • 想控制"上到第几节"：改 config.js 里的 进度（1~4），后面的课会自动锁上。
